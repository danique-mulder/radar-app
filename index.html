Connect to your repo

This page runs checks in your private radar repo and shows the results. It needs a GitHub access key that only works on that repo. The key stays in this browser.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → radar.
  3. Permissions: Actions read and write, Contents read and write.
  4. Generate, copy, and paste it below.
Job sources

Add companies whose career pages should be checked. GitHub looks each one up on Greenhouse, Lever and Ashby and adds the ones it finds. Companies on other platforms (e.g. Workday) need adding in the repo's config.yaml.

Scores in a dashed circle (~) are keyword estimates; they get an AI score on a later check.
